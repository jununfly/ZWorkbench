# UI Spec — ChatGPT Codex 桌面端布局（截图转写）

- 来源：zj 提供的 ChatGPT 桌面应用截图（Codex 模式），2026-10-25
- 状态：临时 ui-spec，仅描述布局，非 ZW 实现承诺；完成后应归档或删除
- 用途：供后续 ZWorkbench Web UI 迭代参考（对比 `app/web/ui-spec/` canonical 产物）

## 整体结构

三栏式桌面布局：极窄图标栏（最左） + 项目导航侧栏 + 主工作区。浅色主题，大量留白，圆角胶囊控件，强调色为橙色（发送按钮/完全访问警告）。

```
┌──┬─────────────┬──────────────────────────────┐
│ 图│  侧栏        │        主工作区               │
│ 标│  (项目列表)  │  居中空态标题                 │
│ 栏│             │                              │
│  │             │        底部: composer          │
└──┴─────────────┴──────────────────────────────┘
```

## 1. 图标栏（最左，~64px 宽，白色背景）

- 顶部：主页（房子）图标
- 中部纵排：历史（时钟）、提及/搜索（@）、更多（…）
- 底部：设置（齿轮）

## 2. 侧栏（~280px 宽）

### 顶部模式切换器
- 当前模式名 "Codex" + 下拉箭头；截图中 popover 展开，含两项单选：
  - **ChatGPT Work** — 副标题"创建、学习和探索"
  - **Codex** — 副标题"构建、调试和发布"，右侧有选中勾
- 切换器右侧同一行：通知铃铛、搜索图标

### 项目/会话树
- 结构：项目（folder 图标 + 名称）为一级节点，其下缩进挂聊天会话；无会话显示灰色占位"暂无聊天"
- 选中态：整行浅灰圆角高亮（截图中 ZAgentic 选中）
- 截图数据示例：skiko / ZWorkbench / ZAgenticOPN / ZAgenticLoop / ZAgentic（选中，含 3 条会话，其中一条以 `$zj-tech-research-report` 开头并带"我"后缀）/ ZCodeGraph / ZCodeReview
- 会话标题为用户首条消息截断，非独立命名

## 3. 主工作区（空态）

- 垂直水平居中：品牌图标（云朵+终端提示符组合，线条风格）→ 大号标题"你想让我们在 {ZAgentic} 中构建什么？"，其中项目名带虚线下划线（可点击/强调当前仓库上下文）
- 无其他卡片或快捷入口，极简空态

## 4. Composer（底部悬浮，圆角胶囊容器）

- 容器上方独立一行**上下文 chips**（浅灰圆角胶囊，带图标）：
  - 仓库 chip：文件夹图标 + "ZAgentic"
  - 环境 chip：显示器图标 + "本地"
  - 分支 chip：git 分支图标 + "main"
- 输入区：占位文本"随心输入"，无边框，占满宽度
- 输入区底缘工具行：
  - 左："+" 附加按钮；"⚠ 完全访问"（橙色文字，权限模式指示，可切换）
  - 右：模型选择器 "5.6 Luna 极高 ⌄"（模型名+推理档位）；圆形橙色发送按钮（上箭头）

## 5. 可借鉴的设计要点（供 ZW 参考）

1. **模式切换器放侧栏顶部**（Work / Codex 双态，带一句话定位副标题）——与 ZW"工作台多模式"潜在需求同构
2. **项目→会话两级树**，空项目显示"暂无聊天"占位而非隐藏
3. **Composer 与上下文 chips 分离**：仓库/环境/分支作为独立可点胶囊，不混入输入文本
4. **权限模式显式化**："完全访问"用橙色警示常驻 composer，权限状态可见
5. **模型+档位内联选择器**置于发送按钮左侧，就近操作
6. 空态用"你想在 X 中构建什么？"把当前上下文（项目名）织入提问句式
