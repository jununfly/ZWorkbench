## six-meaning 定义（分义，不合并）
- screen：一个可命名的页面/视图边界（含占位区）。
- component：该 screen 内可复用的 catalog 组件实例（仅引用 S4 catalog）。
- state：screen/component 的可观测状态集合（含 loading/empty/error/data）。
- action：用户或系统触发的行为（点击/输入/请求/导航）。
- intent：action 背后的目的（用户想达成什么），不得与 action 合并。
- acceptance：该 screen 可被验收的判据（可机器或人工核验）。

## screen: AppShell（全局外壳，所有页共有）
### component
- Sidebar（固定左侧，含 7 个 NavItem 一级项 + NavGroup 二级折叠）
- ContentArea（右侧可滚动区，承载当前 screen）
- NavItem / NavGroup（来自 catalog）
### state
- activeNav: 当前一级项 id（首页/工作台/主题/项目/统计/日志/设置）
- expandedGroups: Set<groupId>（默认空集，点击展开）
- theme: light（默认）| dark（派生，可选）
### action
- 点击一级 NavItem → 切换 activeNav 并路由到对应 screen
- 点击带二级的 NavItem（主题）→ toggle 该 NavGroup 展开/折叠
- 点击二级项（A股投研）→ 路由到 A股投研 screen
### intent
- 在任何一级页面间稳定导航，并清楚标示当前位置（不同背景色 + 图标高亮）
### acceptance
- 7 个一级项全部可点击并可路由；当前项背景色与图标明显区别于其他项
- 二级菜单默认折叠，点击可展开；折叠/展开状态不丢失（同会话）

## screen: Workbench（工作台，一级页，非占位）
### component
- Page（含两个区域：ChatRegion、CodingEvidenceRegion）
- Tabs（页内切换 对话 / 编码证据）或并排双栏（由 S6 preview 定）
- List/ListItem（chat 历史、evidence 事件流）
- ConversationList / ConversationItem（对话历史列表：当前对话背景高亮，每项右键菜单 分享/归档/删除）
- StatusChip（编码证据生命周期态）
- TextField / Button（发送消息、触发 run）
### state
- workbenchTab: chat | evidence
- chat: {conversations[], activeConversationId, messages[], inputDraft, sending}
- evidence: {runs[], selectedRunId, events[], violations[], safeStopState}
### action
- 切换 workbenchTab
- 点击 ConversationItem → 切换 activeConversationId（当前项背景高亮）
- 右键 ConversationItem → 弹出上下文菜单（分享 / 归档 / 删除）
- 选择 分享 → 生成对话分享链接；归档 → 标记该对话为已归档；删除 → 从列表移除该对话
- 新建对话
- 在 chat 输入并发送 → 调 LLM 对话接口
- 在 evidence 选中某 run → 拉取该 run 身份链/事件流/违例
- 触发 safe-stop 审批动作
### intent
- 集中承载非交易的自治生产力（对话 + 编码证据审计）；对话历史可快速切换与管理
### acceptance
- 对话区可输入、可显示消息、可调用后端 /api（沿用现有契约）
- 对话历史列表呈现，当前对话背景高亮；点击切换会话时右侧对话区同步切换为该会话内容；每项右键可触发 分享/归档/删除 菜单并执行对应动作
- 编码证据区可列出 run、显示 7 态 StatusChip、展示身份链与违例审计
- 两个区域均来自 catalog，无未注册组件
